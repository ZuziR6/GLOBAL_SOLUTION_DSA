# Explicação do Projeto

## Estruturas utilizadas
- Lista ligada: gerenciamento dinâmico dos Rovers
- Fila: envio de telemetria em ordem FIFO
- Vetor: usado temporariamente para ordenação e busca

## Algoritmos
- qsort: ordenação por ID
- Busca binária: localização eficiente de Rovers

## Persistência
- Arquivo telemetria.txt armazena dados da frota

## Simulação
- rand() simula desgaste e falhas dos Rovers
